# ระบบอบรมออนไลน์ การประยุกต์ใช้เทคโนโลยีเพื่อการจัดการเรียนการสอน

ระบบอบรมออนไลน์สำหรับครู เลือกเรียนหลักสูตรเทคโนโลยีเพื่อการสอน (Canva, ChatGPT, Gemini, Claude และอื่น ๆ) ผ่านวิดีโอ YouTube ติดตามความก้าวหน้า ทำแบบทดสอบหลังเรียน และดาวน์โหลดเกียรติบัตรได้ทันทีเมื่อผ่านเกณฑ์

ผู้พัฒนา: นายสรวิศ จันพุ่ม ศึกษานิเทศก์ ปฏิบัติหน้าที่ ผอ.กลุ่ม DLICT
สำนักงานเขตพื้นที่การศึกษาประถมศึกษานครศรีธรรมราช เขต 1

## สถาปัตยกรรมระบบ

```
ผู้ใช้ (เบราว์เซอร์)
   │  เปิดหน้าเว็บ
   ▼
GitHub Pages ── index.html, verify.html, assets/
   │  fetch (JSON)
   ▼
Google Apps Script เว็บแอป ── backend/Code.gs (API)
   │
   ▼
Google Sheet (ฐานข้อมูล 9 ชีต)
```

หน้าเว็บทั้งหมดแขวนอยู่บน GitHub Pages ส่วน Google Apps Script ทำหน้าที่เป็น API รับส่งข้อมูลกับ Google Sheet เท่านั้น ข้อมูลผู้เรียนทั้งหมดอยู่ใน Google Sheet ของหน่วยงาน ไม่ได้เก็บไว้บน GitHub

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| index.html | หน้าเว็บหลัก ลงทะเบียน แดชบอร์ด หน้าเรียน แบบทดสอบ ผู้ดูแลระบบ |
| verify.html | หน้าตรวจสอบเกียรติบัตรจากเลขที่หรือคิวอาร์โค้ด |
| assets/css/style.css | รูปแบบการแสดงผล |
| assets/js/config.js | ตั้งค่า URL ของ API (ไฟล์เดียวที่ต้องแก้) |
| assets/js/app.js | การทำงานฝั่งผู้ใช้ |
| backend/Code.gs | โค้ด API สำหรับวางใน Google Apps Script (ไม่ได้ทำงานบน GitHub) |

## ขั้นตอนการติดตั้ง

### ส่วนที่ 1 ฐานข้อมูลและ API (Google Sheet + Apps Script)

1. สร้าง Google Sheet ใหม่ เมนู ส่วนขยาย > Apps Script
2. ลบโค้ดเดิมใน Code.gs แล้ววางโค้ดจาก `backend/Code.gs` (ไม่ต้องสร้างไฟล์ HTML)
3. เลือกฟังก์ชัน `setup` แล้วกด เรียกใช้ อนุญาตสิทธิ์ ระบบจะสร้างชีต 9 แผ่นพร้อมหลักสูตรตัวอย่าง
4. การทำให้ใช้งานได้ > การทำให้ใช้งานได้รายการใหม่ > ประเภท เว็บแอป
   เรียกใช้ในฐานะ: ฉัน
   ผู้มีสิทธิ์เข้าถึง: ทุกคน
5. คัดลอก URL ที่ลงท้ายด้วย `/exec`
6. เลือกฟังก์ชัน `testSendEmail` แล้วกด เรียกใช้ 1 ครั้ง เพื่ออนุญาตสิทธิ์ส่งอีเมล ระบบจะส่งอีเมลทดสอบเข้ากล่องจดหมายของบัญชีที่ติดตั้ง

### ส่วนที่ 2 หน้าเว็บ (GitHub Pages)

1. แก้ไฟล์ `assets/js/config.js` วาง URL จากข้อ 5 แทนข้อความตัวอย่าง
2. ที่ repository ไปที่ Settings > Pages
   Source: Deploy from a branch
   Branch: main และโฟลเดอร์ / (root) แล้วกด Save
3. รอประมาณ 1 ถึง 2 นาที จะได้ที่อยู่เว็บ เช่น `https://ชื่อผู้ใช้.github.io/ชื่อ-repo/`
4. เข้าสู่ระบบด้วยบัญชีผู้ดูแล ไปที่ แท็บ ตั้งค่าระบบ ใส่ที่อยู่เว็บนี้ในช่อง FRONTEND_URL เพื่อให้คิวอาร์โค้ดบนเกียรติบัตรชี้มาที่หน้าตรวจสอบบน GitHub

### บัญชีผู้ดูแลระบบเริ่มต้น

อีเมล `admin@nst1.local` รหัสผ่าน `admin1234`
ต้องเปลี่ยนรหัสผ่านทันทีหลังเข้าสู่ระบบครั้งแรก (เมนู ข้อมูลส่วนตัว) เนื่องจากค่านี้เปิดเผยอยู่ในโค้ดบน GitHub

## การปรับปรุงโค้ดภายหลัง

1. แก้หน้าเว็บ: แก้ไฟล์ใน repository แล้ว commit GitHub Pages จะอัปเดตเองภายในไม่กี่นาที
2. แก้ API: แก้ใน Apps Script แล้วไปที่ การทำให้ใช้งานได้ > จัดการการทำให้ใช้งานได้ > แก้ไข > เวอร์ชัน: เวอร์ชันใหม่ URL เดิมจะยังใช้ได้ ไม่ต้องแก้ config.js

## การยืนยันตัวตนผ่านอีเมล

1. เมื่อลงทะเบียน ระบบส่งรหัสลับ 8 หลักไปยังอีเมลที่สมัคร บัญชีมีสถานะ รอยืนยันอีเมล จนกว่าจะกรอกรหัสถูกต้อง
2. รหัสมีอายุ 10 นาที กรอกผิดได้ไม่เกิน 5 ครั้งต่อรหัส ขอรหัสใหม่ได้ทุก 60 วินาที และไม่เกิน 5 ครั้งต่อชั่วโมง
3. ระบบเก็บรหัสในรูปแบบเข้ารหัส SHA-256 พร้อม salt ใน CacheService ไม่บันทึกรหัสจริงลง Google Sheet และใช้รหัสซ้ำไม่ได้
4. ผู้ที่ลงทะเบียนแล้วยังไม่ยืนยัน เมื่อเข้าสู่ระบบ ระบบจะพาไปหน้ากรอกรหัสโดยอัตโนมัติ
5. ผู้ดูแลกด ยืนยันแทน ได้ในหน้ารายงาน กรณีครูไม่ได้รับอีเมล
6. ปิดการยืนยันอีเมลได้ที่ แท็บ ตั้งค่าระบบ ช่อง REQUIRE_EMAIL_VERIFY
7. อีเมลส่งจาก Gmail ของบัญชีที่ติดตั้ง Apps Script โควตาบัญชี Gmail ทั่วไปประมาณ 100 ฉบับต่อวัน บัญชี Google Workspace ประมาณ 1,500 ฉบับต่อวัน หากเปิดลงทะเบียนพร้อมกันจำนวนมาก ควรติดตั้งด้วยบัญชี Workspace ของหน่วยงาน

## การอัปเดตจากรุ่นก่อน (เพิ่มการยืนยันอีเมล)

1. วาง `backend/Code.gs` ฉบับใหม่ทับใน Apps Script
2. รันฟังก์ชัน `testSendEmail` 1 ครั้ง เพื่ออนุญาตสิทธิ์ส่งอีเมล (สำคัญ หากไม่ทำ การลงทะเบียนจะส่งรหัสไม่ได้)
3. การทำให้ใช้งานได้ > จัดการการทำให้ใช้งานได้ > แก้ไข > เวอร์ชันใหม่
4. อัปโหลด index.html และโฟลเดอร์ assets ทับใน repository ยกเว้น config.js
5. ระบบเพิ่มคอลัมน์ email_verified_at ให้อัตโนมัติ ผู้ใช้เดิมที่มีสถานะ ใช้งาน เข้าสู่ระบบได้ตามปกติโดยไม่ต้องยืนยัน

## การอัปเดตจากรุ่นก่อน (เพิ่มการลงทะเบียนหลักสูตร)

1. วาง `backend/Code.gs` ฉบับใหม่ทับใน Apps Script แล้วทำให้ใช้งานได้เป็นเวอร์ชันใหม่
2. อัปโหลดไฟล์ index.html และโฟลเดอร์ assets ฉบับใหม่ทับใน repository (ไฟล์ config.js เดิมใช้ต่อได้ ไม่ต้องอัปโหลดทับ)
3. ระบบจะสร้างชีต Enrollments และคอลัมน์ enroll_open ให้อัตโนมัติเมื่อมีการใช้งานครั้งแรก ไม่ต้องรัน setup ใหม่
4. ครูที่เริ่มเรียนไว้ก่อนแล้วถือว่าลงทะเบียนหลักสูตรนั้นแล้ว เรียนต่อได้ทันที

## ความสามารถของระบบ

1. ลงทะเบียนเข้าใช้ระบบรายบุคคล ยืนยันตัวตนด้วยรหัสลับ 8 หลักทางอีเมล รหัสผ่านเข้ารหัส SHA-256 พร้อม salt
2. ลงทะเบียนหลักสูตรก่อนเริ่มเรียน ครูดูรายละเอียดหลักสูตรได้ก่อนตัดสินใจ เมื่อยืนยันแล้วบทเรียนจึงเปิดให้เรียน ข้อมูลบันทึกในชีต Enrollments
3. แดชบอร์ดแสดงหลักสูตร ความก้าวหน้า และชั่วโมงอบรมสะสม
4. ติดตามการรับชมวิดีโอด้วย YouTube IFrame API นับเฉพาะวินาทีที่เล่นจริง เกณฑ์เริ่มต้นร้อยละ 80
5. แบบทดสอบหลังเรียน สุ่มลำดับข้อ ทำซ้ำได้
6. เกียรติบัตร PDF และ PNG มีเลขที่และคิวอาร์โค้ดตรวจสอบ
7. ผู้ดูแลเปิดหรือปิดการรับลงทะเบียนรายหลักสูตร จัดการบทเรียน ข้อสอบ ค่าตั้งระบบ ดูจำนวนผู้ลงทะเบียนและรายงานรายบุคคล ส่งออก CSV ได้

## ข้อควรทราบ

1. URL ของ API ใน config.js เป็นข้อมูลสาธารณะได้ เพราะทุกคำสั่งตรวจสิทธิ์ด้วยรหัสการเข้าใช้ที่ได้หลังเข้าสู่ระบบ และคำสั่งของผู้ดูแลตรวจสิทธิ์ผู้ดูแลทุกครั้ง
2. ห้ามนำไฟล์ Google Sheet หรือข้อมูลผู้เรียนมาเก็บใน repository
3. ระบบรองรับผู้ใช้หลักร้อยถึงหลักพันคน ตามข้อจำกัดของ Google Sheet และโควตา Apps Script
